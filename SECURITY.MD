# Security Policy

## Supported Versions

Security updates are provided for the latest stable release of Needlelight.

Development builds and prerelease versions are not considered supported versions for security purposes.

| Version | Supported |
|---|---|
| Latest stable release | Yes |
| Older releases | No |
| Development and prerelease builds | No |

## Reporting a Vulnerability

Please **do not open a public GitHub issue** for security vulnerabilities.

Security issues should be reported privately using [GitHub Security Advisories](https://github.com/Aarav2709/Needlelight/security/advisories) for this repository.

When reporting a vulnerability, please include:

* A clear description of the vulnerability and its potential impact
* The steps required to reproduce it
* A proof of concept or relevant example, when possible
* The affected version or versions
* Your operating system and relevant environment details
* Any other information that may help reproduce or investigate the issue
Providing detailed information helps us investigate the report more quickly.

## Response

We aim to acknowledge security reports within **72 hours**.

After the initial review, we aim to provide a remediation plan, status update, or request for additional information within **7 days**.

Depending on the severity and complexity of the issue, timelines may vary.

## Responsible Disclosure

Please allow reasonable time for the issue to be investigated and, where appropriate, fixed before publicly disclosing the vulnerability.

We appreciate responsible reports and will make a reasonable effort to keep reporters informed throughout the process.
